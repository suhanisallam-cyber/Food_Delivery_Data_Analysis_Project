# Food Delivery Data Analysis

## Project Overview
This project analyzes food delivery data to understand order performance, delivery duration, customer ratings, and popular food items.
The objective is to identify important trends and generate useful insights for improving delivery operations and customer satisfaction.

## Tools & Technologies
- Python
- Pandas
- SQL
- PostgreSQL
- Power BI
- Excel
- CSV file

## Key Analysis
- Cleaned and prepared the dataset using Python.
- Used SQL queries to analyze orders and delivery performance.
- Identified the most frequently ordered dishes.
- Analyzed delivery status and order distribution by city.
- Evaluated average delivery time and customer ratings.
- Built an interactive Power BI dashboard with KPI cards, charts, and filters.

## Conclusion
This project demonstrates the use of Python, SQL, and Power BI to transform raw data into meaningful business insights and support data-driven decision-making.
